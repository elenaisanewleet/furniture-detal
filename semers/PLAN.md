# Semers САЙТ — где лежит план

**Единственный актуальный план этого проекта — Google Документ
«SEMERS САЙТ — план проекта и журнал работ»:**

https://docs.google.com/document/d/1ujy-pnNFxigylCfO1XSHdz6PVT_DGld65oWkTTOyysc/edit

Там Roadmap, протокол, Handoff, задачи, риски и история. Второй план в другом
месте не ведётся — этот файл только указывает дорогу.

**Порядок входа в каждом новом чате:** AI START HERE → HANDOFF → ПРОТОКОЛ →
карточка нужной задачи. Одна задача → один результат → проверка → отчёт из
10 пунктов (HUMAN REVIEW CARD) → STOP перед новым этапом.

GitHub хранит код, тесты, ветки и PR. Результаты и ссылки на PR возвращаются
в документ.

Правила, которые обязана знать каждая сессия, — в `CLAUDE.md` рядом.
Как проект собирается и выкладывается — в `DEPLOY.md`. Устройство кода — в `README.md`.
