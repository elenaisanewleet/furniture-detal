# Мастерская Архангельское

Сайт мебельной мастерской в селе Архангельское, Ульяновская область.
Задача сайта одна — принимать заявки на работу; вторая — местная поисковая
выдача по региональным запросам.

Astro 7, чистый CSS на кастомных свойствах, статическая сборка, Vercel.
Ни UI-фреймворка, ни CSS-фреймворка: тринадцать страниц не окупают ни того,
ни другого, а лишний килобайт в критическом пути на селе стоит дороже, чем
в городе.

## Запуск

```
npm install
npm run dev        # http://localhost:4321
npm run build      # проверка типов и сборка в dist/
npm run preview    # посмотреть собранное
```

## Что где лежит

| Путь | Что это |
|---|---|
| `src/pages/` | Тринадцать страниц. Шесть услуг — из одного шаблона `[service].astro` |
| `src/data/` | Всё содержание: услуги, станки, детали, склад, контакты |
| `src/components/` | Форма заявки, определитель детали, станки, шапка, подвал |
| `src/styles/` | `tokens.css` — палитра и шкалы, `base.css` — примитивы, `site.css` — раскладка |
| `src/lib/` | `schema.ts` — разметка schema.org, `origin.ts` — домен и индексация |
| `src/scripts/` | Клиентский код: форма, голосовое, схемы станков, определитель |
| `api/zayavka.js` | Приём заявок: номер, хранилище, Telegram |
| `public/` | Шрифты, текстуры, 3D-модель, локальный three.js |
| `design/` | Исходный прототип на чистом HTML — дизайн-референс, в сборку не входит |

## Содержание в одном месте

Тексты не живут в разметке. Страница услуги — это запись в
`src/data/services.ts`: заголовок, лид, «что входит», вопросы и ответы,
станки, перелинковка. Поменяли там — поменялось на странице, в карточке на
главной, в подвале, в sitemap и в schema.org одновременно.

То же с контактами (`src/data/site.ts`), станками (`machines.ts`), деталями
(`parts.ts`) и складом (`stock.ts`).

## Чего на сайте нет и быть не должно

Стажа, цен, сроков, гарантий и отзывов — этих фактов у мастера не было.
Наличие на складе формулируется только как «уточните перед поездкой».
Фотографий мастерской в публикацию нет: вместо них чертежи, схемы и
3D-реконструкция, и подписи говорят, что это реконструкция, а не съёмка.

Логотипа не существует. Марка — слово «Мастерская», набранное Golos Text 800
с трекингом −0.05em. Рисовать знак нельзя.

## Настройка

Все переменные — в `.env.example`. Ни одна не обязательна: без них сайт
собирается и работает, просто заявка уходит только в мессенджер.

Подробнее о выкладке и о том, что включается какой переменной, — `DEPLOY.md`.

## Проверки

```
npm run build      # astro check + сборка; ошибок типов быть не должно
```

Перед выкладкой стоит пройти глазами: заявка отправляется и показывает
номер, определитель фильтрует по трём входам, схемы станков раскрываются,
3D-страницы открываются без сети до сторонних доменов.
